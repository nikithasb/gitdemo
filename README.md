# Student Management System

A simple project created to practise Git and GitHub commands.

## Project Files

- students.txt - Stores student details.
- courses.txt - Stores course details.
- marks.txt - Stores student marks.
- config/settings.txt - Stores application settings.
- logs/activity.log - Stores application activity.

## Purpose

This project is used to practise:

- Git status
- Git add
- Git commit
- Git push and pull
- Git restore
- Git reset
- Git revert
- Git stash
- Git branch
- Git merge
- Git rebase
- Git cherry-pick
- Merge conflicts
